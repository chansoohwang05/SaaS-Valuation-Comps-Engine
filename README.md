# Automated SaaS Valuation & Comps Engine

## Project Overview
This project automates the extraction and analysis of Comparable Company Analysis (Comps) data for enterprise SaaS and mega-cap tech equities. It replaces manual spreadsheet tracking with a repeatable Python pipeline and an interactive Tableau BI dashboard.

---

## Technical Stack & Workflow
1. **Data Pipeline (Python / Pandas):**
   * Programmatically extracts fundamental equity metrics (Revenue, Enterprise Value, Growth Rates, Margins) to benchmark valuation multiples.
2. **Business Intelligence (Tableau):**
   * Built an interactive visualization layer allowing stakeholders to compare valuation multiples (EV/Revenue, EV/EBITDA) dynamically across peer groups.

---

## Repository Contents
* `mna_comps_engine.py`: Python script utilizing `yfinance` and `pandas` for financial data processing.
* `tech_valuation_comps.csv`: Structured comparable company output dataset.
* `saas_dashboard.png`: High-resolution visual capture of the SaaS Tableau valuation dashboard.
